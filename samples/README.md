# Sample PDFs

These files are intentionally small and synthetic, designed to exercise the helper functions.

- `born-digital.pdf` — A4, text-only (English)
- `born-digital-ja.pdf` — A4, text-only (Japanese, CID fonts)
- `scanned-image.pdf` — A4, full-page raster image (no PDF text objects)
- `mixed.pdf` — A4, full-page raster image + an invisible/white text layer
- `treacherous.pdf` — a 6-page mix of:
  1. born-digital A4 portrait
  2. scanned-image A4 portrait
  3. mixed A4 portrait
  4. born-digital Letter landscape
  5. scanned-image Letter landscape
  6. born-digital A4 portrait (Japanese CID fonts)
